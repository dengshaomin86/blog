配置全局 Gradle 镜像 ​

groovy
1. 找到或创建全局 init.gradle 文件（路径因系统而异）：

Windows:
C:\Users\<你的用户名>\.gradle\init.gradle

macOS / Linux:
~/.gradle/init.gradle

2. 没有 init.gradle 则创建文件，并写入内容：
allprojects {
    repositories {
        // def ALIYUN = "https://maven.aliyun.com/repository/public" // 版本过时
        def ALIYUN = "https://repo.huaweicloud.com/repository/maven/"
        def JCENTER = "https://maven.aliyun.com/repository/jcenter"
        def GOOGLE = "https://maven.aliyun.com/repository/google"
        def GRADLE_PLUGIN = "https://maven.aliyun.com/repository/gradle-plugin"

        all { ArtifactRepository repo ->
            if (repo instanceof MavenArtifactRepository) {
                def url = repo.url.toString()
                if (url.contains("jcenter")) {
                    repo.setUrl(JCENTER)
                } else if (url.contains("google")) {
                    repo.setUrl(GOOGLE)
                } else if (url.contains("gradle")) {
                    repo.setUrl(GRADLE_PLUGIN)
                } else if (url.contains("central")) {
                    repo.setUrl(ALIYUN)
                }
            }
        }

        // 添加备用仓库（防止 repo 替换失败）
        maven { url ALIYUN }
        maven { url JCENTER }
        maven { url GOOGLE }
        maven { url GRADLE_PLUGIN }
    }
}

项目内设置（局部） ​

groovy
// 如果不想全局影响，可以在项目根目录的 build.gradle 或 settings.gradle 中添加：
repositories {
    maven { url 'https://maven.aliyun.com/repository/public' }
    maven { url 'https://maven.aliyun.com/repository/jcenter' }
    maven { url 'https://maven.aliyun.com/repository/google' }
    mavenCentral()
    google()
    jcenter()
}

镜像地址 ​

  • 阿里云 https://maven.aliyun.com/repository/public
  • 华为云 https://repo.huaweicloud.com/repository/maven/
  • 清华镜像 https://mirrors.tuna.tsinghua.edu.cn/maven/
  • 中科大镜像 https://mirrors.ustc.edu.cn/

webpack 与 vite 区别 ​

webpack ​

  • 改变代码，编译所有文件（不管有没有改动，全部重新编译，消耗性能），打包放在内存，显示
  • 打包原因：浏览器兼容，文件合并
  • 过程：vue-cli-service serve => build => bundle(内存) => 启动 web server

vite ​

  • 过程：vite serve => 启动 web server

优点 ​

  • 只更新更新过的代码
  • 开发环境不打包

使用 ​

  • npm init vite@latest
  • npm init @vitejs/app
  • vue2 插件 vite-plugin-vue2

qiankun 原理 ​

基于 single-spa 进行了二次封装，通过“协议接入”的方式解决了子应用的加载、沙箱隔离、资产预加载等痛点。

# 其核心原理可以概括为以下四个主要维度：
1. 路由劫持与应用加载
qiankun 继承了 single-spa 的路由拦截机制。它通过监听浏览器地址栏的变化（hashchange 或 popstate），匹配当前 URL 对应的子应用配置。

HTML Entry: 与 single-spa 要求子应用导出 JS 链接不同，qiankun 采用 HTML Entry 方式。它直接请求子应用的 HTML 地址。

解析过程: 内部使用 import-html-entry 库，解析 HTML 获取其中的 DOM 结构、CSS 链接和 JS 链接。

渲染: 将子应用的 HTML 内容填充到主应用指定的容器（Container）中。

2. 环境沙箱隔离（Runtime Sandbox）
这是 qiankun 的核心难点，确保多个应用在同一个窗口运行时互不干扰。

JS 沙箱 (JS Sandbox):

SnapshotSandbox (快照沙箱): 适用于不支持 Proxy 的旧浏览器。应用启动前记录 window 状态，卸载前对比差异并记录，恢复主应用环境。

LegacySandbox: 基于 Proxy，通过单例模式记录对 window 的修改。

ProxySandbox (多例沙箱): 为每个子应用创建一个独立的 fakeWindow。所有对全局变量的读写都在这个伪造的对象上进行，从根源上隔离了不同应用对全局环境的影响，支持多个子应用同时存在。

样式沙箱 (CSS Sandbox):

Strict Style Isolation: 利用 Shadow DOM 将子应用完全包裹。这是最彻底的隔离，但可能导致 Modal/Popover 丢失样式。

Experimental Scoping: 类似于 Vue 的 scoped 方案，qiankun 会自动为子应用的 CSS 规则增加前缀选择器（如 div[data-qiankun="app1"]）。

3. 应用间通信
虽然微前端提倡应用解耦，但必要的通信不可或缺。

发布订阅模型: qiankun 提供了一套全局状态管理机制（initGlobalState）。

数据流: 主应用定义全局状态，子应用通过 onGlobalStateChange 监听变化，通过 setGlobalState 修改状态。这种设计是响应式的，确保了应用间的同步。

4. 资源预加载（Prefetch）
为了提升用户体验，qiankun 会在主应用空闲时（利用 requestIdleCallback）预先下载未激活子应用的静态资源。当用户真正点击切换时，资源已在缓存中，从而实现“秒开”的效果。


# 核心执行流程图示
用户切换 URL -> 匹配子应用路由。

Fetch HTML -> 获取子应用的 entry 页面。

运行 JS 沙箱 -> 创建独立的执行环境。

执行子应用生命周期 -> 调用子应用导出的 bootstrap、mount 钩子。

挂载 DOM -> 将内容渲染到 Container。

卸载 -> 触发 unmount，销毁沙箱，清理全局污染。

Why Not Iframe ​

为什么不用 iframe，这几乎是所有微前端方案第一个会被 challenge 的问题。但是大部分微前端方案又不约而同放弃了 iframe 方案，自然是有原因的，并不是为了 "炫技" 或者刻意追求 "特立独行"。

如果不考虑体验问题，iframe 几乎是最完美的微前端解决方案了。

iframe 最大的特性就是提供了浏览器原生的硬隔离方案，不论是样式隔离、js 隔离这类问题统统都能被完美解决。
但他的最大问题也在于他的隔离性无法被突破，导致应用间上下文无法被共享，随之带来的开发体验、产品体验的问题

1. url 不同步。浏览器刷新 iframe url 状态丢失、后退前进按钮无法使用。
2. UI 不同步，DOM 结构不共享。想象一下屏幕右下角 1/4 的 iframe 里来一个带遮罩层的弹框，同时我们要求这个弹框要浏览器居中显示，还要浏览器 resize 时自动居中..
3. 全局上下文完全隔离，内存变量不共享。iframe 内外系统的通信、数据同步等需求，主应用的 cookie 要透传到根域名都不同的子应用中实现免登效果。
4. 慢。每次子应用进入都是一次浏览器上下文重建、资源重新加载的过程。

其中有的问题比较好解决(问题1)，有的问题我们可以睁一只眼闭一只眼(问题4)，但有的问题我们则很难解决(问题3)甚至无法解决(问题2)，而这些无法解决的问题恰恰又会给产品带来非常严重的体验问题， 最终导致我们舍弃了 iframe 方案。

FFmpeg 视频旋转处理命令 ​

  • -vf 指令是一些简单的视频过滤器

顺时针旋转 90° ​

bash
ffmpeg -i input.mp4 -vf "transpose=1" input-r90.mp4

逆时针旋转 90° ​

bash
ffmpeg -i input.mp4 -vf "transpose=2" input-r270.mp4

水平翻转 ​

bash
ffmpeg -i input.mp4 -vf hflip input-hflip.mp4

垂直翻转 ​

bash
ffmpeg -i input.mp4 -vf vflip input-vflip.mp4

不转码，仅设置旋转: 快速、无损、秒完成 ​

-i input.mp4	输入文件
-c copy	音视频都直接拷贝，不转码
-metadata:s:v:0 rotate=90	设置第一个视频流的旋转角度为 90°
# ffmpeg -i input.mp4 -c copy -metadata:s:v:0 rotate=90 output.mp4 # 新版本不可用
bash
ffmpeg  -display_rotation:v:0 90 -i input.mp4 -c copy output.mp4
bash
# 查看当前视频的旋转信息
ffprobe -v quiet -select_streams v:0 -show_entries stream_side_data=rotation -of default=nw=1:nk=1 input.mp4

C 盘清理 ​

1. 清理临时文件 ​

快捷键按下 WIN + R，输入

bash
%TEMP%

直接删除全部文件就行，不能删除的跳过。

2. 禁用休眠功能 ​

管理员执行下面命令：

bash
# 关闭
powercfg -h off

# 打开
powercfg -h on
